Android doesn't let an MDM set RustDesk's server silently. Do this once per device:

  1. On the device open Remote Support (or press Open RustDesk on the Devices page).
  2. Go to Settings → ID/Relay server and tap the QR scan icon.
  3. Scan this code, then tap OK.
  4. On the Share screen tab, start the service and allow screen capture + accessibility.
